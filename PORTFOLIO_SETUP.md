# Portfolio setup checklist

## Suggested GitHub repository

**Repository name:** `casa-vicenta-boarder-management`

**Description:** Full-stack boarder/property management system built with React, Cloudflare Workers, D1, and R2, with a safe interactive portfolio demo.

**Topics:** `react`, `vite`, `cloudflare-workers`, `cloudflare-d1`, `cloudflare-r2`, `property-management`, `full-stack`, `portfolio`

## After pushing to GitHub

1. Open **Settings → Pages** and use **GitHub Actions** as the source.
2. Run or wait for **Deploy portfolio demo to GitHub Pages**.
3. Copy the generated Pages URL into the repository **Website** field.
4. Add the Pages URL to your portfolio project card as **Live Demo**.
5. Pin the repository on your GitHub profile if this is one of your stronger full-stack projects.

## Suggested portfolio card copy

**Casa Vicenta Boarder Management System**

Full-stack property management platform for room occupancy, applicants, monthly utility billing, payment receipt verification, complaints, and boarder statements. Built with React + Cloudflare Workers/D1/R2. Includes a safe sample-data demo for public viewing.

## What to show a client first

Use the demo switcher at the top of the live site:

- **Admin Demo** for operational workflows and data tables.
- **Boarder Demo** for billing, receipts, statements, and requests.
- **Public Site** for the customer-facing application flow.

The public demo contains no production credentials or tenant data and does not write to a backend.
