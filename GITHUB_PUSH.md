# Push this repository to GitHub

This project is already initialized as a Git repository on the `main` branch.

## 1. Create the empty GitHub repository

Create a new repository named:

`casa-vicenta-boarder-management`

Recommended settings:
- Visibility: Public
- Do **not** add a README, .gitignore, or license during creation (they are already in this project).

## 2. Push

From this folder, run:

```bash
git push -u origin main
```

The `origin` remote is already configured for:

`https://github.com/aydeloreabaquita/casa-vicenta-boarder-management.git`

## 3. Turn on the live portfolio demo

After the push finishes:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Select **GitHub Actions** as the source if needed.
4. Open **Actions** and confirm **Deploy portfolio demo to GitHub Pages** completes successfully.
5. Add the generated Pages URL to the repository Website field and your portfolio.
